   Рабочая папка - это папка, в которой производятся основные работы над поставленными задачами.
   Индекс - это порядковый номер какого-либо элемента.
   Коммит - это зафиксированное состояние проекта в определённый момент времени. Своего рода сохранение в игре.
   Git является системой контроля версий, которая работает локально, а GitHub - облачный сервис для хостинга проектов, основанных на Git.


==Использованные команды==
   git status - это команда Git, которая показывает какие файлы изменены, какие уже в индексе и что готово к коммиту.
   git diff сравнивает рабочую директорию с индексом, т.е. показывает изменения, которые ещё не были добавлены через git add.
   git diff --staged сравнивает индекс с последним коммитом, т.е. показывает, что уже добавлено и попадает в следующий коммит.

==Ветки==
   Ветка - указатель на коммит. Просто "стикер", который прикреплён к последнему коммиту в цепочке, которые не является отдельной папкой или копией файла. При новом коммите указатель ветки просто сдвигается вперёд на этот новый коммит.
   Слияние - это операция, которая объединяет изменения из одной ветки в другую.
